# Инструкции по запуску и использованию проекта

Этот документ содержит инструкции по установке, запуску и использованию веб-приложения для транскрипции и суммаризации аудио.

## 1. Предварительные требования

Перед началом убедитесь, что у вас установлены:
- **Python 3.8+**
- **pip** (менеджер пакетов Python)
- **Redis**: Это система управления базами данных, которая используется в качестве брокера сообщений для Celery. Её необходимо установить и запустить.
  - Для Windows можно использовать [Memurai](https://www.memurai.com/) или WSL.
  - Для macOS: `brew install redis` и `brew services start redis`.
  - Для Debian/Ubuntu: `sudo apt-get update && sudo apt-get install redis-server`.
- **FFmpeg**: Это сторонняя утилита, которая необходима `openai-whisper` для обработки и конвертации аудиофайлов.
  - Для Windows: Скачайте сборку с официального сайта [ffmpeg.org](https://ffmpeg.org/download.html), распакуйте архив и добавьте путь к папке `bin` в системную переменную `PATH`.
  - Для macOS: `brew install ffmpeg`.
  - Для Debian/Ubuntu: `sudo apt-get update && sudo apt-get install ffmpeg`.

## 2. Установка зависимостей

1.  Клонируйте или скачайте этот репозиторий.
2.  Откройте терминал или командную строку в директории проекта.
3.  Установите все необходимые Python-библиотеки с помощью файла `requirements.txt`:

    ```bash
    pip install --upgrade -r requirements.txt
    ```
    *Примечание: Флаг `--upgrade` гарантирует, что пакеты будут обновлены до версий, указанных в файле `requirements.txt`. Установка `torch` и `openai-whisper` может занять некоторое время и потребовать значительного дискового пространства.*

## 3. Запуск приложения

Приложение состоит из двух основных компонентов, которые нужно запустить в **двух отдельных терминалах**: веб-сервера Flask и обработчика задач Celery.

### Терминал 1: Запуск обработчика Celery

В первом терминале запустите Celery worker. Он будет ожидать и выполнять задачи по обработке аудио в фоновом режиме.

```bash
celery -A app.celery worker --loglevel=info --pool=solo
```
*Использование `--pool=solo` рекомендуется для Windows или в случаях, когда возникают проблемы с параллельной обработкой моделей. Для Linux/macOS можно убрать этот флаг.*

Вы должны увидеть сообщение, что Celery готов к приему задач. Не закрывайте этот терминал.

### Терминал 2: Запуск веб-сервера Flask

Во втором терминале запустите веб-сервер Flask.

```bash
python app.py
```

Сервер будет запущен в режиме отладки. Вы увидите сообщение, что сервер работает и слушает порт (обычно `http://127.0.0.1:5000`).

## 4. Использование приложения

1.  Откройте веб-браузер и перейдите по адресу, указанному при запуске Flask (например, `http://127.0.0.1:5000`).
2.  **Выберите файл**: Нажмите на область загрузки или перетащите туда аудиофайл.
3.  **Настройте параметры**:
    - Выберите нужную модель Whisper (`small`, `medium`, `large`). Модели `large` и `medium` более точные, но требуют больше времени и ресурсов.
    - При необходимости введите "стар-слова" (для остановки транскрипции) и "стоп-слова" (для удаления из текста).
4.  **Нажмите "Загрузить и обработать"**.
5.  **Отслеживайте прогресс**: Появится прогресс-бар, отображающий статус обработки. Вы можете отменить задачу с помощью кнопки "Отменить".
6.  **Просмотрите результаты**: По завершении обработки появятся вкладки с результатами:
    - **Транскрипция**: Полный распознанный текст.
    - **Транскрипция с метками**: Текст с временными отметками.
    - **Суммаризация**: Краткое изложение текста.
7.  Вы можете скопировать текст из любого поля или сохранить его в файл `.txt` с помощью кнопки "Сохранить".
8.  Для обработки нового файла нажмите "Обработать еще".
